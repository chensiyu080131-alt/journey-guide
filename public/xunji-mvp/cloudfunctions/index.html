本地数据（localStorage 模拟云数据库）

本控制台在浏览器内用 localStorage 模拟 checkins / collections 两个集合，打卡与统计都基于它，刷新不丢失。


    

      说明：微信云函数源码位于 weapp/cloudfunctions/，使用 wx-server-sdk 连接云数据库，
      需在微信开发者工具「上传并部署」并配置 AppID 后才能真正上云（见 README）。
      本控制台为免后端的可视化操作/测试版，逻辑与云函数一致。
    

  


  

    💡 想用命令行跑通逻辑？运行 node cloudfunctions/local-test.mjs（仓库内自带，无需任何依赖）即可看到 getRoutes / checkin / stats 的完整 JSON 输出。
