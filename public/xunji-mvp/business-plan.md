# 商业方案文档（business-plan）

> 目标：验证「传统文学+现代文旅」商业闭环。竞品数据见 [./competitor-analysis.md](./competitor-analysis.md)；MVP 设计见 [./mvp-design.md](./mvp-design.md)。团队所在地未定，政策补贴以通用+示例列出，详见 [./BLOCKED.md](./BLOCKED.md)。
> 原则：能落地 > 有数据 > 好看。凡非一手数据均标"估算/参考来源"。

## 一、商业模式画布（9 格）
| 格 | 内容 |
|----|------|
| 客户细分 | B端：景区、文旅局、文化机构；C端：文学/文旅爱好者、亲子研学、年轻游客 |
| 价值主张 | 轻量小程序：选诗→文学路线地图→AI导览（原文+解读+背景+打卡）→集卡；B端数据看板 |
| 渠道 | 微信小程序（搜索/自然流量）；政企合作直销（B端）；文旅局推荐 |
| 客户关系 | C端社区+分享海报；B端专属客户经理+数据月报 |
| 收入来源 | B端采购/定制开发费/年费/分成；C端会员/文创/研学包 |
| 核心资源 | 公版文学IP（古诗词）、AI生成能力、内容库、小程序 |
| 关键业务 | 内容生产（AI+人工）、小程序运营、B端试点交付 |
| 重要伙伴 | 景区/文旅局、微信云开发、AI模型厂、地方政府（补贴） |
| 成本结构 | 人力、内容生产、服务器、运营推广 |

## 三、成本结构表
| 项 | 金额（估算） | 依据 |
|----|-------------|------|
| MVP 开发人力 | 3–4.5 万 | 30人天×1000–1500元（mvp-design） |
| 内容生产（首批10诗+审核） | 含在人力内 | AI生成边际≈50元/剧本（泉州案例，人民网） |
| 服务器 | 0 元（云开发免费层） | 微信云开发免费额度；超出约50–500元/月 |
| 运营推广 | 0–1 万/月 | 首批靠政企合作0成本引流；C端投放另计 |

## 四、里程碑甘特图（文字描述）
- **第1月**：MVP 开发（前端+云开发+种子内容，见 mvp-design）+ 签约 1 个免费试点景区。
- **第2月**：试点部署 2 周 + 采集数据（参与人数/打卡热力/用户画像）+ 快速迭代。
- **第3月**：产出试点数据报告 + 本商业方案定稿 + 向 ≥3 家景区/文旅局递 [合作提案](./partnership-proposal.md)。
- **第4–6月**：复制模式（≥3 景区）、C 端会员上线、启动政策补贴申请。
> 验证锚点：泉州用"12万参与/200万营收增量"证明轻量闭环可行（人民网 2026-06-23），本项目 3 月目标定为单景区试点数千参与+可复制。

## 六、最大风险
1. **试点数据获取难**→ 先用行业公开数据（泉州等）+ 最小模拟试点，注明参考。
2. **B端决策周期长**→ "免费试点2周"降低门槛（见提案模板）。
3. **AI 内容合规**→ 人工审核关卡 + 公版文学无版权风险。
