寻迹 · 传统文学 + 现代文旅 小程序

本目录托管「寻迹」微信小程序的完整源码，由 journey-guide 仓库的 public/xunji-mvp/ 自动发布。

如何导入微信开发者工具

  1. 克隆仓库或下载本目录。
  2. 打开微信开发者工具 → 导入项目。
  3. 项目目录选择 weapp/ 文件夹（含 app.js / app.json / project.config.json）。
  4. AppID 可使用「测试号」；如需真实云开发，替换 app.js 中的 USE_CLOUD 与 CLOUD_ENV。

目录结构

  • weapp/ —— 小程序前端（首页 / 路线 / 分享海报 / B端统计 四页）
  • weapp/cloudfunctions/ —— 3 个云函数：getRoutes / checkin / stats
  • db/literary-routes.json —— 单一数据源：10 首诗 / 20 个景点 / 10 条路线
  • selftest.js —— Node 模拟器自测（本地 28/28，云端 34/34）
  • competitor-analysis.md / mvp-design.md / business-plan.md / partnership-proposal.md —— 商业文档
  • PROGRESS.md / BLOCKED.md —— 进度与待决事项

运行模式

默认 USE_CLOUD = false（本地模式）：无需后端即可体验打卡、路线、海报。切换为 true 并填入云环境 ID 后，打卡与统计数据接入微信云开发。

最后更新见仓库提交记录。
