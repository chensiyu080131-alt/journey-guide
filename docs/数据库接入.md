# 寻迹 · PostgreSQL 接入说明

> 选型：托管 Postgres（Neon / Supabase）  
> 拍板：1B 托管库 · 2B 核验内容+书单+全国浅覆盖 · 3B dashboard 内容编辑

## 1. 创建数据库

任选其一：

### Neon（推荐上手）

1. 打开 [https://neon.tech](https://neon.tech) 注册  
2. Create project → 复制 **Connection string**（含 `sslmode=require`）  
3. 写入本地 `.env.local`：

```bash
DATABASE_URL="postgresql://...@....neon.tech/neondb?sslmode=require"
```

### Supabase

1. 新建项目 → Settings → Database → Connection string（URI）  
2. 同样写入 `DATABASE_URL`

生产环境：把同一变量加到 ECS `.env.production` / GitHub Secrets。

## 2. 初始化表结构并导入内容

```bash
cd /Users/yu/Projects/journey-guide
npm install
npx prisma generate
npm run db:push          # 按 schema 创建表（开发期）
npm run db:seed          # 从 mock-data / city-books 等导入
npm run db:studio        # 可选：可视化浏览
```

Seed 会导入：

- `mockGuides`（含常熟、江苏城、全国浅覆盖、人间滋味）
- `cityBooksMap`（城市书单）

## 3. 应用行为

| 场景 | 行为 |
|------|------|
| **无 `DATABASE_URL`** | 读文件 Mock；dashboard 编辑器只读提示 |
| **有 `DATABASE_URL`** | `/api/content` 优先读库；可 PATCH 点位 |
| 库故障 | 自动回退文件，避免整站空白 |

相关代码：

- `prisma/schema.prisma` — 表结构  
- `prisma/seed.ts` — 导入脚本  
- `lib/content-repo.ts` — 仓储（DB / 文件双读）  
- `app/api/content/route.ts` — 列表 / 详情 / 书单 / 统计 / 更新点位  
- `components/dashboard/content-editor.tsx` — 工作台编辑器  

## 4. 自检

```bash
curl -s 'http://localhost:3000/api/content?stats=1' | python3 -m json.tool
curl -s 'http://localhost:3000/api/content?id=shajiabang' | python3 -c "import sys,json;d=json.load(sys.stdin);print(d['source'], d['guide']['title'])"
```

期望：`databaseConfigured: true`，`source: "database"`。

打开 `/dashboard` → **内容编辑器** 改一处原文 → 保存 → 再刷攻略页验证。

## 5. 注意

- Prisma Client 在 `postinstall` / `build` 时 `generate`，CI 需能跑通（可不连真实库也能 generate）  
- `db:push` / `db:seed` **必须**有有效 `DATABASE_URL`  
- 不要把生产库连接串提交进 git
