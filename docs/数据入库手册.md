# 数据入库手册

**仓库：** https://github.com/journey-guide/journey-guide  
**数据库：** Supabase（`routes` / `points` / `cards` / `checkins`）

---

## 双写原则

1. **先改 JSON**：`public/xunji-mvp/db/<slug>.json`
2. **再入库**：跑 seed 脚本（或 SQL）
3. **再注册**：新路线还要在 `lib/route-detail-data.ts` 增加 import，静态页才能生成

只改库、不改 JSON → 下次静态构建会漂移。

---

## JSON 最小字段

### route

| 字段 | 说明 |
|---|---|
| `slug` | 英文短链，唯一 |
| `title` / `author` / `city` / `book` / `summary` | 必填 |
| `plain_explain` / `why_worth` | 白话与行动理由（推荐） |
| `category` | `scenic` / `literary` / `figure` |
| `season` | `spring` / `summer` / `autumn` / `winter` |
| `source` | `human` \| `ai` |

### points（建议 5 个）

| 字段 | 说明 |
|---|---|
| `seq` / `name` / `address` | 必填 |
| `lng` / `lat` | **GCJ-02（高德）** |
| `excerpt` / `excerpt_source` | 原文 + 出处 |
| `excerpt_confidence` | 见下表 |
| `interpretation` / `checkin_task` | 解读 + 现场任务 |
| `photo` / `illustration` | 文学卡片图（可选 URL，站内路径如 `/images/route-cards/...`） |
| `panorama` / `panorama_source` | 全景（可选） |

### 引文分级

| 值 | 前端文案 | 何时用 |
|---|---|---|
| `verified` | 原文实据 | 原文确写该地/该景，出处可核对 |
| `derived` | 主题引用 | 原文主题相关，或地名有延伸/置换，须在 `excerpt_source` 写明 |
| `pending` | 出处待考 | 句或出处未核清；**禁止冒充 verified** |

## 密钥

| 变量 | 用途 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 项目 URL（可进前端） |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | 公开读（**不能写** routes/points） |
| `SUPABASE_SERVICE_ROLE_KEY` | 写入 seed（**仅本地 `.env.local`，禁止提交仓库 / 发群**） |

`.env.local` 已在 `.gitignore`。

## 操作步骤

### 1）首次 / 扩列（必做一次）

打开 https://supabase.com/dashboard/project/dnfuqobsgtmyinmruovn/sql/new  
依次运行：

1. `supabase/migrate-route-enrichment.sql`（plain_explain / photo 等）
2. `supabase/migrate-route-v2.sql`（duration / baike_summary 等规范 V2 字段）

（API secret 无法执行 DDL，必须控制台跑。）

跑完后再执行下面的 seed，新列才会被填上。

### 2）灌数

```bash
node --env-file=.env.local scripts/seed-routes-supabase.mjs
```

备选：`supabase/seed-all-routes.sql`（控制台粘贴；大文件，改完 JSON 后请重新生成）。

### 3）验收

```bash
curl -s "$NEXT_PUBLIC_SUPABASE_URL/rest/v1/routes?select=slug" \
  -H "apikey: $NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY" \
  -H "Authorization: Bearer $NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY"
```

看 `points` 的 `excerpt_confidence` 分布与卡片 `photo`/`illustration` 是否非空；V2 扩列后可再查 `baike_summary`。
